# Arc Harness wiki

Status: Works today. This page is the map of the wiki.

Arc Harness is a desktop app where an AI model works in sessions. A kit of scripts builds it from your own copy of the original app.
This wiki explains how to build it, how to run it, and what is planned. The file `README.md` in the main repository gives the short version.

Every page starts with a Status line. It says one of three things.

- **Works today.** You can use it now.
- **Partly.** Some of it works. The page says which part.
- **Planned.** It does not exist yet. The page describes the plan.
