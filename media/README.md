# Media

The clips explain how Arc Harness and its memory work. They are drawn animations from the project's explainer deck. They are not recordings of the app.

## Workflow clips

Each clip is 1280 x 720, H.264, 12 frames per second, no sound.

| File | What it shows | Length |
|---|---|---|
| `gates.mp4` | A task is accepted only when all five gates pass. The ledger is a hash chain, and repeats become lessons. | 48 s |
| `better.mp4` | A policy patch counts as better only on a paired test on held-out tasks, with a budget for false positives. | 50 s |
| `ranking.mp4` | Memory search merges four ranked lists by rank fusion, and a reranker improves the top 5. | 42 s |
| `student.mp4` | A small student model learns the big reranker's scores. | 52 s |
| `context.mp4` | A context packer sorts notes into hot, warm and cold tiers. The design target is ten times less context. | 51 s |
| `gates.gif`, `ranking.gif` | The same two films at double speed, 720 px, for the README. | 24 s, 21 s |

Each clip marks its own numbers: "concept values" are examples, "targets" are design goals, and "measured" are results.
