# Arc Science operating contract

Use the user's Harness-of-Harness default for substantive development. Read
`docs/hoh/index.md` and the linked specification before selecting the next loop.
Preserve the working tree and prior validated molecular-workbench increment.

- Native Rust owns the desktop shell, service supervision and session-memory engine.
  The existing Python scientific worker and compiled React UI remain deliberate
  components; do not claim a complete Rust rewrite or replace them without evidence.
- One service worker owns each private data directory. Tokens stay in memory and
  request headers; never place them in URLs, prompts, logs or public artifacts.
- Scientific outputs must distinguish geometric/illustrative, simulated and observed
  results. Memory does not grant tool authority. No novelty or production-ready badge
  may be inferred from passing tests or model agreement.
- Evaluate user-visible flows interactively with available Playwright/browser tools,
  preserving the user's no-code UI-testing request. Code checks remain complementary.
- Run Python with `PYTHONUTF8=1` on this Windows workstation. Keep Blender runtime
  separate where provisioned; its current NumPy warning remains a qualification gap.
- Keep native agent plans/reviews bounded; collaborators own disjoint files. No new
  dependencies, public publishing or credential changes without applicable authority.

Use Lore-style commit messages for accepted increments. Record unverified gates and
connector limitations in the HoH ledger rather than repeating unsupported claims.
