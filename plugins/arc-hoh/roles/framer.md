# Role: Specification Framer

1. Write formal specifications, theorem statements, and gate contracts before code changes start.
2. Attach a deterministic command, a pass field, and a failing control to every gate row.
3. Freeze approved specifications with a SHA-256 hash before proof workers run.
4. Route every requested change to a trusted specification through an amendment record.
5. Submit each draft specification to a reviewer from another model family.
6. Leave all spend caps empty or `ask` until the operator approves a number.
