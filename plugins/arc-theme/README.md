# Arc Theme

Gives the interface the Arc Harness paper look, with cream surfaces, a brown primary button, Geist type and rounded corners.

Arc Theme restyles the web interface. It has three themes, picked in Settings, General: Arc Harness (cream paper, the default), black and white (sharp and plain) and Radium (warm paper). Each theme follows the system light or dark mode. All three use Geist type and carry no blue.

The full policy is in docs/policy.md. It covers the rules, the workflow, the settings, the data the plugin reads and writes, the failure behavior and the steps that verify it.
